# 💧 Monitoramento de Reservatório de Água

Projeto desenvolvido em **Python** para simular um sistema de monitoramento do nível de água de um reservatório.

O programa exibe no terminal uma mensagem para cada nível de água, utilizando cores diferentes para facilitar a identificação da situação.

## 📊 Níveis do reservatório

| Nível | Situação | Cor |
|---|---|---|
| 1 | Muito baixo (crítico) | 🔴 Vermelho |
| 2 | Baixo | 🟡 Amarelo |
| 3 | Médio | 🟢 Verde |
| 4 | Alto | 🔵 Ciano |
| 5 | Muito alto (alerta) | 🔵 Azul |

## 🛠️ Tecnologias utilizadas

- **Python**
- **Colorama**

## 📚 Conceitos utilizados

Neste projeto foram utilizados:

- Listas;
- Funções;
- Estruturas condicionais `if`, `elif` e `else`;
- Estrutura de repetição `for`;
- Importação de biblioteca;
- Cores no terminal.

## 📁 Estrutura do projeto

```text
monitoramento-reservatorio/
├── app.py
├── README.md

```

## 📦 Instalação

Primeiro, instale a biblioteca **Colorama**:

```bash
pip install colorama
```

Ou utilize o arquivo `requirements.txt`:

```bash
pip install -r requirements.txt
```

## ▶️ Como executar

Execute o arquivo principal:

```bash
python app.py
```

O programa irá simular os cinco níveis do reservatório e mostrar cada situação com sua respectiva cor.

## 🎯 Objetivo

O objetivo deste projeto é praticar o uso de **listas, funções, estruturas condicionais, estruturas de repetição e bibliotecas Python**, simulando uma situação de monitoramento de um reservatório de água.
