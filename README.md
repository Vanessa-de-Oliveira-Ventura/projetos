## 📌 Sobre o Projeto
Este é um sistema simples desenvolvido em Python para calcular o consumo mensal de energia elétrica de aparelhos eletrodomésticos, ajudando no controle e conscientização dos gastos residenciais.

## 🧮 Fórmula Utilizada
O cálculo do consumo mensal em kWh é feito com base na seguinte fórmula matemática:

$$\text{Consumo Mensal (kWh)} = \frac{\text{Potência (W)} \times \text{Horas de Uso Diário} \times 30 \text{ dias}}{1000}$$

> **Bônus:** O sistema também calcula o custo estimado em reais utilizando uma tarifa fixa de **R$ 0,75 por kWh**.

1. Certifique-se de ter o **Python** instalado em sua máquina.
2. Abra o terminal na pasta do projeto.
3. Execute o comando abaixo:
   ```bash
   python app.py
   ```
4. Insira os dados solicitados pelo terminal e veja o resultado na tela.
