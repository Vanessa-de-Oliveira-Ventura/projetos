Projeto em **Python** que calcula automaticamente o desconto de uma compra e mostra o valor final a pagar.

## 📌 Sobre o Projeto

O programa solicita o valor da compra, aplica o desconto conforme a faixa de preço e exibe um resumo da compra no terminal.

## 🚀 Funcionalidades

* Recebe o valor da compra.
* Calcula o desconto automaticamente.
* Mostra o desconto e o total a pagar.

## 💸 Faixas de Desconto

| Valor da compra    | Desconto |
| ------------------ | -------- |
| Menor que R$ 200   | **5%**   |
| R$ 200 a R$ 299,99 | **10%**  |
| R$ 300 ou mais     | **15%**  |

## 🖥️ Exemplo

```text
Digite o valor total da compra: R$ 250

--- Resumo da compra ---
Valor da compra: R$ 250.00
Desconto aplicado: 10%
Valor do desconto: R$ 25.00
Total a pagar: R$ 225.00
```

## 🛠️ Tecnologias

* Python 3
* Visual Studio Code

## ▶️ Como Executar

1. Abra o arquivo `.py`.
2. Execute o programa.
3. Digite o valor da compra.
