# 📊 Pesquisa de Opinião – TudoWeb

Programa desenvolvido em **Python** para realizar uma pesquisa de satisfação com **50 entrevistados**, registrando a opinião de cada pessoa sobre o atendimento da empresa TudoWeb.

## 🎯 Objetivo

Coletar e contabilizar as avaliações dos entrevistados, classificando-as em três categorias:

* **1 – Excelente**
* **2 – Bom**
* **3 – Ruim**

Ao final da pesquisa, o programa exibe a quantidade de respostas de cada categoria.

## 🛠️ Tecnologias utilizadas

* Python 3

## ▶️ Como executar

1. Abra o terminal ou o VS Code.
2. Execute o arquivo Python:

```bash
python pesquisa_opiniao.py
```

3. Responda às perguntas para cada um dos 50 entrevistados.

## 📋 Funcionamento

Para cada entrevistado, o programa solicita:

* Nome.
* Idade.
* Opinião sobre o atendimento.

As respostas são contabilizadas automaticamente durante a execução.

## 📌 Exemplo de uso

```text
--- Entrevistado 1 ---
Digite o nome: Gustavo
Digite a idade: 16

Opinião sobre o atendimento:
1 - EXCELENTE
2 - BOM
3 - RUIM

Digite a opção: 1
```

## 📈 Exemplo de saída

```text
--- Resultado da Pesquisa ---
Quantidade de respostas EXCELENTE: 22
Quantidade de respostas BOM: 18
Quantidade de respostas RUIM: 10
```
